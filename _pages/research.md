  <section class="research-prose-section">
    <h2 class="research-prose-title">On-device AI</h2>
    <p class="research-prose">As mobile applications increasingly rely on deep neural networks, efficient and accurate execution on resource-constrained devices has become critical. We develop system techniques across the model, runtime, and hardware stack: DynaStitch dynamically reconfigures vision transformers through neural stitching <span class="research-cite">[EMSOFT '26]</span>; viNPU optimizes vision transformer inference on mobile NPUs <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3767295.3803619" target="_blank" rel="noopener">[EuroSys '26]</a>; and ARIA coordinates heterogeneous mobile processors to enable real-time vision foundation model inference for augmented reality <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3711875.3729161" target="_blank" rel="noopener">[MobiSys '25]</a>. Together, these efforts aim to make advanced AI models practical, responsive, and energy-efficient on everyday mobile and edge devices.</p>
  </section>

  <section class="research-prose-section">
    <h2 class="research-prose-title">Energy-aware mobile systems</h2>
    <p class="research-prose">Reducing energy consumption is a persistent challenge for mobile systems. We investigate system-level energy optimization across native applications <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3307334.3326075" target="_blank" rel="noopener">[MobiSys '19]</a>, mobile web browsing <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3300061.3345449" target="_blank" rel="noopener">[MobiCom '19]</a> <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3757918" target="_blank" rel="noopener">[EMSOFT '25]</a>, and mobile games <a class="research-cite" href="https://ieeexplore.ieee.org/document/9352566" target="_blank" rel="noopener">[TMC '22]</a>. We also design energy-efficient on-device AI techniques for ultra-low-power sensing <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3761806" target="_blank" rel="noopener">[TECS '25]</a> and computation-intensive mobile vision workloads <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3680207.3765252" target="_blank" rel="noopener">[MobiCom '25]</a>.</p>
  </section>

  <section class="research-prose-section">
    <h2 class="research-prose-title">Mobile immersive computing</h2>
    <p class="research-prose">Immersive media such as omnidirectional and volumetric video can deliver interactive and engaging mobile experiences, but their large data sizes and computational demands create substantial systems challenges. We develop techniques that maximize visual quality under strict time, bandwidth, and resource constraints, including super-resolution-enhanced live 360-degree video streaming <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3581791.3596851" target="_blank" rel="noopener">[MobiSys '23]</a>, energy-optimized super-resolution for mobile devices <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3680207.3765252" target="_blank" rel="noopener">[MobiCom '25]</a>, and fully immersive volumetric video streaming based on 3D Gaussian splatting <a class="research-cite" href="https://dl.acm.org/doi/10.1145/3680207.3765267" target="_blank" rel="noopener">[MobiCom '25]</a>.</p>
  </section>

  <section class="research-prose-section">
    <h2 class="research-prose-title">Cross-device computing</h2>
    <p class="research-prose">As users increasingly interact with multiple personal devices, cross-device computing has become an important part of the mobile experience. Our research pursues platform-agnostic methods by leveraging the web as a common meta-platform. We have examined how users experience the mobile web <a class="research-cite" href="https://ieeexplore.ieee.org/document/9488671" target="_blank" rel="noopener">[INFOCOM '21]</a> and developed techniques for sharing device I/O across web applications <a class="research-cite" href="https://ieeexplore.ieee.org/document/10228950/" target="_blank" rel="noopener">[INFOCOM '23]</a> and distributing graphical interfaces across devices <a class="research-cite" href="https://ieeexplore.ieee.org/document/10621433" target="_blank" rel="noopener">[INFOCOM '24]</a>.</p>
  </section>
